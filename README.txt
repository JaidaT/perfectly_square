# Perfectly Square by Jaida Tarlit

## Overview
Perfectly Square is a simple cost spitter for two.  
You can edit usernames, split costs by percentage, and view a detailed history of previous expenses.  
Perfectly Square also provides a Currency Converter with over 20 currencies to choose from.  

## Features
### Custom Users 
Edit users at any time under the Edit Users section. The currently saved usernames will be displayed in the input fields.  
Editing a username will update that username across the page. One or both usernames can be updated at one time.  

### Adding Expenses
All fields are required to be filled to add an expense.  
To add an expense: 
* Select the initial paying user
* Give the expense a name (eg. Rent, Groceries, Food)
* Input the total amount of the expense
* Input the % of the cost the intial paying user is responsible for paying for
* Click the "Add Expense" button to calculate the dollar amount the other user owes

### Currently Owed
The Currently Owed section displays the amount owed per the latest added expense.  
To clear the display for currently owed amount, simply click the "Clear" button to reset both amounts to $0.  

### Expense History
The Expense History gives a detailed history of the previously added expenses.  
Details include:
* Date of when the expense was added
* Expense name
* Total expense amount
* Dollar amount each user was responsible for paying

### Currency Converter
The Currency Converter is powered by [ExchangeRate-API](https://www.exchangerate-api.com/).  
Simply select the base currency and the currency you'd like to convert to, and click the "Convert" button to get the result.  
Optionally, provide a custom amount to the "From" field to convert the specified amount.
